# Coming Soon Poster Design — GSX-LAUNCHCTRL

## Layout Brief

### Format
- **Size:** 24" × 36" (print), 1080 × 1350 (digital)
- **Orientation:** Vertical portrait
- **Background:** Obsidian Black (#080B10)

### Visual Hierarchy

```
┌─────────────────────────────────────┐
│                                     │
│     [GSX-LAUNCHCTRL wordmark]       │
│         (top center, 15% from top)  │
│                                     │
│         [Blue light sweep]          │
│         across center of poster     │
│                                     │
│   "LAUNCH SMARTER. EXECUTE HARDER." │
│         (center, bold, cyan)        │
│                                     │
│   "Power Under Control."            │
│         (below tagline, silver)     │
│                                     │
│   [Wet floor reflection]            │
│   [Blue superbike silhouette]       │
│         (bottom 40%)                │
│                                     │
│   "COMING SOON"                     │
│   [GitHub URL] [Social handles]     │
│         (bottom, small, silver)     │
│                                     │
└─────────────────────────────────────┘
```

### Color Applications

| Element | Color | Usage |
|---------|-------|-------|
| Background | Obsidian Black (#080B10) | Full bleed |
| Wordmark GSX | Clean White (#F5F7FA) | Primary text |
| Wordmark LAUNCHCTRL | Electric Cyan (#21C8FF) | Accent |
| Tagline | Electric Cyan (#21C8FF) | Primary message |
| Secondary tagline | Metallic Silver (#C7D0DC) | Supporting text |
| Redline accent | Redline Red (#FF3048) | Small details, tachometer |
| URLs / Socials | Metallic Silver (#C7D0DC) | Footer info |

### Typography

| Element | Font | Weight | Size |
|---------|------|--------|------|
| GSX-LAUNCHCTRL | Space Grotesk | 900 | 15% of height |
| Primary tagline | Space Grotesk | 700 | 8% of height |
| Secondary tagline | Inter | 400 | 4% of height |
| Footer info | IBM Plex Mono | 400 | 2.5% of height |

### Clear Space

Minimum 10% of width on all sides. No text or graphics in clear space.

### Usage

- Print posters for tech events, garages, co-working spaces
- Digital posters for social media (Instagram, Twitter, LinkedIn)
- Email newsletter header
- Website hero background
